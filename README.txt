# Portfolio fotograficzne

## 1. Podgląd
Otwórz `index.html` dwuklikiem w przeglądarce.

## 2. Dodawanie zdjęć
1. Wrzuć swoje zdjęcia do folderu `images`.
2. Otwórz `index.html` w Notatniku / VS Code.
3. Znajdź np.:
   `<div class="placeholder"><span>01</span><small>WSTAW SWOJE ZDJĘCIE</small></div>`
4. Zamień go na:
   `<img src="images/photo-01.jpg" alt="Opis zdjęcia">`

Możesz potem dopasować wygląd zdjęcia w `style.css`.

## 3. Zmiana tekstów
W `index.html` zmień:
- TWOJE IMIĘ
- opis w sekcji O mnie
- adres e-mail
- Instagram/Facebook
- nazwy kategorii
- tytuły prac

## 4. Darmowe opublikowanie 24/7
Najprościej przez GitHub Pages:
1. Załóż konto na GitHub.
2. Utwórz publiczne repozytorium o nazwie `twojanazwa.github.io`.
3. Wrzuć do niego `index.html`, `style.css`, `script.js` oraz folder `images`.
4. Wejdź w Settings → Pages.
5. Włącz publikowanie z gałęzi `main`.
6. Po chwili strona będzie pod `https://twojanazwa.github.io`.

GitHub Pages może hostować tę statyczną stronę bez płatnego serwera.
